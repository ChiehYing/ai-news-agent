## 1. Gemini API File Search is now multimodal

`RAG` `Multimodal` `File Search` `Gemini API`

**來源：** hackernews | **評分：** 13 | [原文連結](https://blog.google/innovation-and-ai/technology/developers-tools/expanded-gemini-api-file-search-multimodal-rag/)

### 摘要

Gemini API File Search 現已加入多模態功能，能同時處理文字與圖像，並提供自訂 metadata 與頁面級引用。這讓開發者在 RAG 流程中更有效率地過濾噪聲、提升答案可驗證性。透過 metadata 篩選，只搜尋特定標籤的資料，並可直接指向原始來源，增強系統可信度。這些功能可立即應用於正在構建agents的開發者，特別是使用 Python 與 Ollama（如 qwen3:14b）的情境。

**Key Insight:** 多模態搜尋結合自訂 metadata 與頁面級引用，使 RAG 系統同時具備高效過濾與可驗證性。

### 學習筆記

對於已掌握 RAG 基礎、開始自行開發agents的你，可在 현대 Python 환경與 Ollama (qwen3:14b) 上快速實作圖像檢索，利用 metadata 限定查詢範圍，並透過 citations 提供使用者可追蹤的來源，提升應用可信度與開發效率。
