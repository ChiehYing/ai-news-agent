## 1. Show HN: Semble – Code search for agents that uses 98% fewer tokens than grep

`Code Search` `Agents` `RAG` `Token Efficiency`

**來源：** Hacker News | **評分：** 119 | [原文連結](https://github.com/MinishLab/semble)

### 摘要

Semble 是一個為 agents 設計的代碼搜索庫，能即時返回精準的代碼片段，相比傳統的 grep+read 節省約 98% 的 token。它的索引和查詢速度極快，於 CPU 上完成全倉庫的索引僅需約 250 毫秒，查詢僅需約 1.5 毫秒，且不需要 API 金鑼、GPU 或外部服務。Semble 支援作為 MCP 伺服器或 Bash 工具直接集成到 Claude Code、Cursor、Codex 等代理框架，讓代理能夠使用自然語言查詢而不是關鍵字搜索。使用 Semble 可讓代理在不離開自然語言的情況下獲得相關代碼上下文，顯著減少手動搜索和閱讀全文件的步驟。

**Key Insight:** Semble 透過自然語言查詢在 CPU 上即時提供精準代碼片段，將 token 使用降低 98% 且無需外部服務。

### 學習筆記

將 Semble 設為 MCP 伺服器，讓你的 agents 在需要代碼上下文時自動使用 natural language query，避免手動 grep；同時利用其 CPU-only、零 API 金鑼的特性降低部署成本與複雜度。

### 摘要

### 摘要

文章說明如何 Audit 查詢混合，找出 60–80% 的查詢不需要高階模型，從而降低 API 支出。透過分析查詢特徵（如是否涉及程式碼、數學、多語言），可決定最經濟的模型，例如對簡單 Q&A 使用免費或 $0.0006/1K token 的 Groq 模型。建議利用 A3M Router 等工具建立路由層，自動將查詢導向最便宜的合適模型，並在失敗時提供後備機制。實戰案例顯示，將成本較高的查詢佔比減半可節省數百美元的月費用，整體可達 40–70% 的成本下降。此指南提供了具體腳本與模型成本圖譜，幫助開發者快速實施成本優化策略。

**Key Insight:** 大部分查詢皆可使用低成本模型處理，僅複雜問題才需要高價模型，這是降低 LLM 支出的關鍵所在。

### 學習筆記

先針對你的應用執行查詢特徵抽取，再將每類查詢對應至最便宜的模型，最後部署具備回退機制的路由器，即可顯著削減 API 成本。

## 9. CapCut paywalled basic features, so this open-source, browser-based alternative just hit 48K stars on GitHub.

`Open Source` `Video Editing` `CapCut` `Browser-Based`

**來源：** Reddit | [原文連結](https://mindwiredai.com/2026/05/16/opencut-the-free-open-source-capcut-alternative-with-48k-github-stars/)

### 摘要

OpenCut 是一個開源、瀏覽器基礎的影片剪輯工具，取代了 CapCut 付費牆後的免費替代方案，已在 GitHub 獲得 48,000 多點星星。該工具在瀏覽器中直接處理影片，無需安裝、無需登入，且所有影片處理都在本機完成，保護隱私且適合商用。OpenCut 目前提供基本的剪切、裁切、多軌道排程等功能，未來路線圖包括特效、文字與色彩校正等進階功能。雖然仍處於早期 Alpha 階段，但已具備足以供社交媒體剪輯、自由 lance 剪輯與教育用途的核心功能。從技術角度看，它使用 Next.js、TypeScript、Bun 等現代網頁技術，展示了全客戶端媒體處理的可行性。

**Key Insight:** OpenCut 以瀏覽器原生、零成本且注重隱私的方式提供影片剪輯功能，為用戶提供了相對 CapCut 更開放的替代方案。

### 學習筆記

如果你需要在本機完成影片剪輯且不想使用雲端服務，可嘗試 OpenCut，其 MIT 授權與持續成長的社群使其成為開源影片編輯的有力選項。
