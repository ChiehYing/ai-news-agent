## 6. Project Glasswing: what Mythos showed us

`Cybersecurity` `LLM` `Vulnerability Research` `AI Safety`

**來源：** Hacker News | **評分：** 266 | [原文連結](https://blog.cloudflare.com/cyber-frontier-models/)

### 摘要

文章探討了使用安全導向的大型語言模型（如 Mythos Preview）進行漏洞查找的實驗。Mythos 能自動鏈結多個漏洞生成完整的漏洞利用鏈並驗證，顯著提升了從單一缺陷到可操作 exploit 的效率，但仍面臨一致性、噪音與偏差等問題，特別是在 C/C++ 程式碼上。研究顯示，僅靠通用代理不足以可靠地執行漏洞研究，需要額外的安全保護機制與嚴格的後置驗證流程。

### 學習筆記

如果你從事安全測試或漏洞自動化，可將 LLM 輸出與傳統驗證工具結合，採用多次提示與樣本過濾策略，以提高生成可驗證 exploit 的可靠性。

## 9. I Cut My LLM API Bill by 73% — Here's the Exact Optimization Playbook

`Cost Optimization` `LLM` `API` `Scaling` `Performance`

**來源：** DEV.to | [原文連結](https://dev.to/kollittle/i-cut-my-llm-api-bill-by-73-heres-the-exact-optimization-playbook-ei5)

### 摘要

文章列出六項具體技巧：先用簡易模型分類路由 request，將高頻輕量查詢導向低價模型；建立快取層減少重複查詢的 API 調用；明確設定輸出 token 上限、使用 max_tokens 限制；壓縮 prompt、刪除無用指令；批次處理非即時任務以降低成本；最後蒸餾小模型以取代高價模型。將這些方法組合使用，成功將月度 API 費用從 4200 元降至 1130 元，降幅 73%。

**Key Insight:** 透過路由、快取、Token 預算、Prompt 壓縮、批次處理與模型蒸餾等手段，可大幅降低 LLM 的運營成本，使 AI 服務在成本效益上更具可持續性。

### 學習筆記

在管理大規模 LLM 服務時，應先建立請求分類與快取機制，設定嚴格的輸出長度限制，並考慮為重複性高的工作蒸餾小模型，以降低 API 預算同時維持輸出品質。
