## 1. Stop wasting tokens and re explaining your project between sessions

`Recall` `Claude Code` `Memory`

**來源：** Hacker News | **評分：** 55 | [原文連結](https://github.com/raiyanyahya/recall)

### 摘要

Recall 是一個完全離線的記憶工具，為 Claude Code 提供 durable memory。它透過 .recall/history.md 記錄每一次會話，並用本地的 TF‑IDF+TextRank 演算法產生約 1–2K token 的 context.md，避免重新解釋整個專案。這意味著有時候不會額外消耗模型 token，且所有資料都保留在本機，符合隱私要求。對於在 Ollama、qwen3:14b 或其他本地模型上實作 Agent 的使用者，Recall 可作為簡單的記憶層，顯著減少重複溝通的成本。

**Key Insight:** 本地提示無需模型呼叫，使用 TF‑IDF+TextRank 產生 compact summary，避免額外 token 消費

### 學習筆記

在開發 Agent 時，可將 Recall 插件整合至專案，利用其自動捕捉的 session log 與本地壓縮 summary 來管理對話歷史，特別適用於離線或本地模型環境，可減少對 API 金鑰與使用 credit 的依賴
