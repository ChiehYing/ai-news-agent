## 1. Show HN: ctx – Search the coding agent history already on your machine

`Agent` `CLI` `Search` `RAG` `History`

**來源：** Hacker News | **評分：** 20 | [原文連結](https://github.com/ctxrs/ctx)

### 摘要

ctx 是一個開源 CLI，能夠將過往 coding agent 會話索引存入本機 SQLite，並提供搜尋功能讓後續 agents 直接取回先前的決策、失敗嘗試、指令與筆記。它支援以關鍵字、檔案路徑或多條件搜尋，並保持所有歷史資料私密、局部運行，無需雲端服務或 API 金鑰。透過結構化的事件與會話資料，agents 能以 far fewer tokens 重用先前的人類或 agent 所獲得的上下文，大幅提升效率。此工具讓 agents 不必從零開始，而能在已有經驗的基礎上快速前進。

**Key Insight:** 透過本地 SQLite 指數化過往 agent 會話，讓當前 agents 能以少量 token 重用先前的決策與失敗經驗，避免重複嘗試。

### 學習筆記

在開發自己的 agents 時，可先安裝 ctx、設定會話索引，利用 ctx search 取回相關歷史內容，再將其融入 prompt，以減少 token 使用並提升決策品質。

## 3. Show HN: CLI that helps AI agents avoid vulnerable dependencies

`Security` `Vulnerability` `CLI` `Dependency`

**來源：** Hacker News | **評分：** 7 | [原文連結](https://github.com/clidey/deptrust)

### 摘要

deptrust 是一個本地 CLI 工具，能夠同時檢查 npm、PyPI、crates.io、Go modules 等多個套件倉庫的版本是否存在已知安全漏洞，並以 AST based taint tracking 提供精確的風險分析。它既可直接作為 CLI 使用，也可作為 MCP server 供 Claude Code、Cursor 等 agent 使用，並在 CI 流程中自動掃描 Pull Request，拋出高危漏洞並給出建議。工具會回傳風險分數、安裝建議以及受影響的生態系，讓 AI agents 在選擇依賴時能夠更謹慎，避免使用有已知漏洞的版本。整體上，deptrust 為 agents 提供了在本地即時驗證安全性的能力，無需依賴雲端服務。

**Key Insight:** deptrust 在本地直接查詢各大套件倉庫的安全性資料，提供風險分數與安裝建議，避免 AI agents 使用有已知漏洞的依賴。

### 學習筆記

在開發 AI agents 之前，可將 deptrust 加入 pre‑commit hook 或 CI pipeline，讓每次提交都能自動檢查依賴的安全性，確保部署的模型與工具不會因漏洞而受到攻擊。

`Personalization` `AI` `Web` `Agentic`

### 摘要

**Key Insight:** Adobe 的 'agentic site' 以即時根據使用者意圖組裝網頁，展示未來網站能為每位使用者完全客製化，且成本與延遲已可接受。

### 學習筆記

若你想探索這類個性化網站，可從模組化內容結構與 LLM 組合生成開始，並留意 latency 與成本指標，確保在實際部署時能維持良好體驗。

## 5. Skill engineering and the case against one-shot AI design

`Skill Engineering` `AI Design` `Prompt` `Creativity`

**來源：** Latent Space | [原文連結](https://www.latent.space/p/skill-engineering-design)

### 摘要

Skill engineering 為 AI agents 提供一套具體的設計詞彙，讓人類能以 'bolder'、'quieter'、'denser' 等指令精確 steer 代理的輸出，而不是讓 agents 只能依靠一次性大提示完成設計。這種方法在避免一次性 AI 設計的同時，仍保留了人類在風格、層次與語系決定中的關鍵角色。作者強調，技能工程不是要取代設計師，而是為他們提供更精細的控制面，使最終產品更貼合使用者需求。此概念也適用於多 agent 系統的協作，讓不同 agents 能共享同一套語彙化的設計規則。

**Key Insight:** 技能工程旨在為 AI agents 提供精確的設計詞彙，讓人類在創作過程中保持 steering，而不是讓 agents 只能靠一次性提示完成設計。

### 學習筆記

在使用 Impeccable 等工具時，可學習並應用既定的設計詞彙，讓 agents 根據這些詞彙調整介面，同時保持人類對最終審美判斷的掌控。

## 6. Building Business Intelligence Tools with LLM

`BI` `LLM` `SQL` `Prompt Engineering`

**來源：** DEV.to | [原文連結](https://dev.to/shashank_ms_6a35baa4be138/building-business-intelligence-tools-with-llm-32af)

### 摘要

LLM 正在把商業智慧 (BI) 從靜態儀表板轉變為語言驅動的互動式介面，讓分析師能用自然語言詢問資料庫並即時取得表格、圖表與敘述性摘要。透過提供完整的 schema 上下文、結構化輸出（如 JSON）以及支援長上下文模型，系統能在不犧牲成本的情況下處理複雜的多步推理。Oxlo.ai 等平台以 request‑based 定價模式提供 DeepSeek V4 Flash 等支援 1M token 的模型，使得即使是龐大的資料庫 schema 也不會產生額外的 token 費用。這些特性讓開發者能快速構建可擴展、可預測成本的 AI 驅動 BI 代理。

**Key Insight:** LLM 讓 BI 介面從圖形化工具轉向語言查詢，關鍵在於提供完整的 schema 上下文並保持輸出結構化，以支援複雜的多步推理。

### 學習筆記

在構建自己的 BI agent 時，可利用 request‑based 定價的長上下文模型，搭配嵌入式檢索只抓取相關 schema，並使用 JSON 模式約束確保輸出可靠。

## 7. Secure Your AI Agents in CI/CD: AgentGuard GitHub Action is Live

`Security` `CI/CD` `AgentGuard` `AI Safety`

**來源：** DEV.to | [原文連結](https://dev.to/dockfixlabs/secure-your-ai-agents-in-cicd-agentguard-github-action-is-live-3047)

### 摘要

AgentGuard 是一款即時在 CI/CD 流程中掃描 AI agent 程式碼的安全工具，無需額外設定即可自動偵測 prompt injection、工具濫用、資料外洩、憑證暴露等 10 大 OWASP ASI Top 10 風險。它利用 AST based taint tracking 進行精細追蹤，並在 Pull Request 中以 SARIF 格式呈現結果，幫助團隊在審查階段即刻捕捉潛在攻擊面。整個流程既支援 GitHub Action 也可作為本地 CLI 或 MCP server 使用，適用於任何 AI agent 的開發工作流程。因此，AgentGuard 為 AI 代理的安全部署提供了第一道防線。

**Key Insight:** AgentGuard 透過 AST taint tracking 在 CI 中即時偵測 AI agents 的安全風險，涵蓋 OWASP ASI Top 10，確保每次 PR 都能被安全掃描。

### 學習筆記

將 AgentGuard 加入你的 GitHub Actions 流程，設定 min‑severity 為 HIGH，即可在每次 Pull Request 時自動檢查敏感操作與潛在注射風險，避免安全疏漏。
