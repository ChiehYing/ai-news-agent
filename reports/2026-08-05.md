## 10. AI Memory Is Not a Trust Model for Team Knowledge

`AI memory` `Team knowledge` `Trust model` `Git` `Reviewable` `Knowledge sharing`

**來源：** DEV.to | [原文連結](https://dev.to/xtsoftwarelabs/ai-memory-is-not-a-trust-model-for-team-knowledge-4j5j)

### 摘要

文章論述單純的 AI 記憶無法成為團隊可信的知識基礎，因為缺乏可審查與追溯機制。它提出將提取的上下文以 Markdown 檔案形式保存在 Git 倉庫中，並 through pull request 進行審核，只有經過人工驗證的內容才能被加入代理的上下文。這種做法確保了知識的來源、修改歷史以及回滾能力，讓團隊能夠在協作時保持透明與安全。最終，記憶變成可版本化、可審查的資產，而非不可靠的黑箱。

**Key Insight:** 將 AI 收集的上下文以 Markdown 形式存入 Git，必經 pull request 審核才能納入代理上下文，從而建立可信、可審查的團隊知識庫

### 學習筆記

在設計團隊協作的 AI 代理時，可導入 Git 版本化與審核流程，使得僅經過審核的知識才能被代理使用，確保決策基礎的可信度
